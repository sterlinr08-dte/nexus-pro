# 2026-09-20 14:00 — Botón "Registrar pago" en menú de chat WhatsApp (v58.62)

## Solicitud

El dueño pidió agregar un botón en el menú de acciones de la ventana de chat de WhatsApp para registrar un pago rápidamente sin salir de la conversación.

## Implementación

### `parches-whatsapp-chat-acciones.js`

Agregado un nuevo botón en `openMainMenu()`, entre "Abrir ficha CRM" y "Marcar como no leído":

```html
<button data-a="pago" ${c?'':'disabled'}>
  <i class="ti ti-cash"></i>
  <span>Registrar pago</span>
</button>
```

Handler:
```javascript
else if(a==='pago'){
  closePop();
  const x=clienteActual();
  if(x && typeof window.abrirAbono==='function') window.abrirAbono(x.id);
  else toastSafe('info','No se puede abrir el formulario de pago');
}
```

- El botón se deshabilita si el chat no está vinculado a un cliente (`disabled` cuando `clienteActual()` es null).
- Usa `abrirAbono(id)` — la misma función de pago que ya se usa en la Ficha CRM (Cliente 360), Facturas y Cobros.
- `abrirAbono` abre el modal estándar "Registrar pago" con selección de deuda, banco, monto y referencia.
