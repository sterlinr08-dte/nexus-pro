# Recomendaciones visuales — burbujas de mensajes WhatsApp

## Solicitud del dueño

El dueño compartió una captura real del chat de WhatsApp de NEXUS PRO y pidió sugerencias concretas para mejorar la apariencia de las burbujas/mensajes, dejando la recomendación documentada para que Claude la lea antes de implementar.

## Qué se observa en la captura

La estética general azul/glass funciona, pero los mensajes salientes se sienten demasiado voluminosos y poco naturales para un chat moderno:

- las burbujas largas ocupan casi todo el ancho útil;
- hay demasiado padding vertical y horizontal;
- el texto se ve muy grande y pesado, especialmente en MAYÚSCULAS;
- el interlineado hace que mensajes de 2–3 líneas se conviertan en bloques muy altos;
- la hora queda demasiado separada del texto y visualmente "flotando" dentro de la burbuja;
- el indicador de leído (doble check circular morado) es demasiado grande y roba protagonismo;
- el radio de las esquinas es exagerado para el tamaño de la burbuja;
- la pequeña cola/triángulo de la burbuja no se integra bien con el cuerpo;
- la separación vertical entre mensajes consecutivos es demasiado amplia;
- el contraste azul claro + borde azul funciona, pero puede verse más fino y menos "tarjeta";
- el resultado se parece más a tarjetas de sistema que a una conversación fluida.

## Recomendación visual

### 1. Reducir el ancho máximo de mensajes de texto

En móvil, los mensajes salientes normales deberían usar aproximadamente **76–82% del ancho disponible**, no casi todo el contenedor. Los mensajes cortos deben conservar `width: fit-content` y nunca estirarse artificialmente.

Para multimedia sí se puede permitir un ancho mayor, aproximadamente 86–90%.

### 2. Compactar padding y altura

Para mensajes de texto:

- padding horizontal aproximado: **10–12 px**;
- padding superior: **8–9 px**;
- padding inferior: **6–7 px**;
- sin `min-height` artificial.

La altura debe depender del contenido real.

### 3. Tipografía menos pesada

Evitar que el chat fuerce apariencia de título. Recomendación móvil:

- tamaño de texto: **13–14 px**;
- `font-weight` normal/semibold, no 800/900;
- `line-height`: **1.30–1.38**;
- conservar exactamente las mayúsculas/minúsculas escritas por el usuario: **no usar `text-transform: uppercase` en las burbujas**.

Los mensajes largos deben leerse como conversación, no como encabezados.

### 4. Integrar hora + estado al pie derecho

La hora y el estado deben vivir juntos en una sola línea compacta al pie derecho de la burbuja.

Objetivo:

`12:41 p. m.  ✓✓`

- tamaño de hora: 9–10 px;
- menor contraste que el mensaje;
- margen superior de 3–4 px;
- sin dejar un hueco grande entre texto y metadata.

### 5. Reducir el check de leído

El círculo morado actual es demasiado dominante.

Preferencia:

- usar doble check pequeño estilo WhatsApp/Telegram, sin círculo grande;
- si se conserva el efecto Aura, reducirlo a un detalle de **14–18 px máximo**, con sombra muy tenue;
- no debe competir visualmente con el contenido.

### 6. Radios más equilibrados

Propuesta:

- radio general de 16–18 px;
- esquina de salida (superior/inferior según diseño) más corta, 5–7 px, para dar sensación de burbuja real;
- evitar radios gigantes de 30–40 px que convierten el mensaje en una tarjeta.

### 7. Cola de burbuja más sutil

La cola triangular debe ser pequeña y formar parte del mismo fondo/borde de la burbuja. Si no se puede integrar correctamente con el glass actual, es preferible **eliminar la cola** antes que dejar un triángulo aislado.

### 8. Menos separación entre mensajes consecutivos

Cuando dos mensajes seguidos son del mismo emisor:

- gap vertical: **3–5 px**;
- cuando cambia el emisor: **7–10 px**.

Esto hace que el hilo se sienta más fluido y permite ver más conversación por pantalla.

### 9. Mantener el estilo Azul Aura, pero más liviano

No eliminar el concepto visual aprobado. Mantener:

- fondo azul claro/translúcido;
- borde muy fino;
- blur/glass sutil;
- animación de entrada/envío existente.

Pero reducir sombra, brillo y volumen para que el mensaje sea el protagonista y no el contenedor.

### 10. Mensajes largos

Para textos largos como "SE ESTAN HACIENDO UNOS AJUSTES...":

- alineación a la izquierda, no centrada;
- ancho limitado;
- texto normal, no aspecto de cartel;
- wrapping natural;
- hora/estado al pie derecho.

La alineación centrada solo tendría sentido para mensajes de sistema, no para conversación normal.
