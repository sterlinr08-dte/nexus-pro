# Móvil — corrección estructural del sidebar y barra superior

El dueño mostró una captura real en iPhone/Safari y pidió corregir dos zonas:

1. la parte inferior izquierda del sidebar, donde el panel blanco cerrado dejaba una gran forma/gota blanca visible bajo la curva azul;
2. la barra superior móvil, que quedaba visualmente tapada/desalineada por el nuevo carril azul fijo.

Pidió: **"Hazlo tú perfecto sin errores"**.

Esta entrega se desarrolla en rama y se deja lista para revisión. No se fusiona a `main` sin una autorización explícita de publicación para esta entrega concreta.

## Diagnóstico

La captura confirmó dos problemas estructurales:

- el sidebar móvil quedó fijo en `left:0`, pero `.main` todavía ocupaba 100% del viewport, por lo que el carril azul se montaba encima del dashboard y encima del lado izquierdo de la barra superior;
- el panel blanco `.sb::after`, cuando estaba cerrado, se dejaba parcialmente visible dentro de los 76px del rail mediante `translateX(calc(-202px + var(--nx-rail)))`. Como la máscara azul se recoge en la parte inferior, esa porción blanca aparecía como una gran gota/placa blanca abajo.

## Cambios implementados

Archivo:
`parches-sidebar-curva.css`

### 1. El dashboard empieza después del carril azul

En móvil:

```css
.main{
  margin-left:var(--nx-rail);
  width:calc(100% - var(--nx-rail));
  flex:0 0 calc(100% - var(--nx-rail));
}
```

Resultado esperado:
- el rail azul deja de tapar contenido;
- el dashboard ya no queda cortado a la izquierda;
- la barra superior tampoco queda detrás del rail;
- al abrir el sidebar, el drawer blanco se superpone sobre el contenido sin volver a desplazarlo.

### 2. Panel blanco completamente oculto cuando el drawer está cerrado

Antes:
`translateX(calc(-202px + var(--nx-rail)))`

Ahora:
`translateX(-100%)`

Abierto:
`translateX(0)`

Esto elimina la gran forma blanca visible en la parte inferior cuando el rail está cerrado.

Cuando se abre, el panel blanco entra desde detrás del azul y ocupa `left:0`, por lo que sí rellena correctamente toda la zona que la curva azul deja libre.

### 3. Barra superior móvil

Sin cambiar botones, funciones ni iconos:

- altura estructural de 56px + safe-area;
- margen exterior de 8px;
- radio de 16px;
- fondo blanco translúcido;
- blur/saturación ligera;
- sombra corta de profundidad;
- botones existentes alineados a 40px;
- menú a la izquierda;
- notificaciones/refrescar a la derecha.

No se crean acciones duplicadas.

### 4. Sombra del rail

Se refuerza ligeramente:
- `drop-shadow(10px 0 16px rgba(15,23,64,.30))`
- segunda sombra corta de 2px/5px.

Objetivo: que al abrir el blanco se perciba claramente que sale desde debajo del azul.

### 5. Iconos

No se modifican los iconos del sidebar.
Se conserva la cascada visual anterior de `parches-seguros-base.js`.
