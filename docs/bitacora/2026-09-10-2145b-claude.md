# Fuera las colitas de las burbujas. Y una nota sobre repintar en vez de arreglar

El dueño pidió quitar la cola. Continúa la tanda visual del chat.

## Lo que había

`parches-whatsapp-inbox.js:124-125` dibujaba dos triángulos:

```css
.nxWaBubWrap.diff-prev.in  .nxWaBub:before{ left:-5px;  top:0; border-top:8px solid rgba(255,255,255,.97) }
.nxWaBubWrap.diff-prev.out .nxWaBub:before{ right:-5px; top:0; border-top:8px solid #d9f99d }
```

Ese `#d9f99d` es verde lima, de una paleta anterior. Pero **el color no era el problema**: están
posicionados en `-5px`, o sea **fuera del cuerpo de la burbuja**. Por eso no se leían como la cola de un
bocadillo sino como un triangulito suelto al lado.

## Lo que ya se había intentado

`parches-whatsapp-aura.js:84` tiene este bloque:

```css
/* Las colas antiguas verdes quedan anuladas visualmente */
… { border-top-color:#d9efff!important }
```

Alguien ya lo había visto y **lo repintó** de verde a azul pálido. El triángulo siguió despegado, solo
que ahora del color correcto. Es un buen ejemplo de arreglar el síntoma: el defecto sobrevivió otra
ronda entera, y el dueño volvió a reportarlo hoy.

## El arreglo

Se **eliminan en el origen**, no se anulan desde una capa posterior. Con el fondo glass actual no hay
forma limpia de integrarlas —habría que recortar el borde y el blur del contenedor— y tanto ChatGPT
(`2026-09-10-2110-chatgpt.md` §7) como yo llegamos a la misma conclusión: mejor quitarlas que dejar un
triángulo aislado.

Queda en su sitio un comentario que explica qué había, por qué se fue y **cuál es el problema a resolver
(el `-5px`) si algún día se quieren de vuelta**.

El repintado de `aura.js` queda como código muerto, así que se retira con su explicación en lugar de
dejarlo ahí confundiendo a quien venga.
