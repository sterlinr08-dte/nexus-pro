## Por qué una sola plantilla y no dos mensajes

Ya se lo expliqué al dueño y queda registrado aquí como decisión: dos mensajes seguidos por el
mismo evento aumenta reportes/bloqueos de Meta y duplica el costo. Una sola plantilla con las
cuentas como texto fijo resuelve las dos cosas.

## Por qué esta sesión NO puede someterla directamente a Meta

`whatsapp-plantilla-crear` exige el JWT de una sesión real del navegador (`resolverAcceso()`
decodifica el `sub` del token y verifica rol admin + organización). Esta sesión no tiene ese
token, y no existe ninguna vía de someter plantillas con la service role key. Someterla es,
además, una acción externa semi-irreversible (un nombre rechazado queda bloqueado en Meta, según
quedó documentado el 2026-09-09 con `pago_confirmado_periodo`) — le corresponde al dueño
ejecutarla desde la pantalla que ya existe para esto, no a esta sesión simular su sesión.
