# v58.78 — body background reforzado con !important

**Fecha:** 2026-09-20
**Autor:** Claude
**Solicitud:** El fondo blanco persistía en iPhone después de v58.75/76/77.

## Diagnóstico

Las versiones anteriores (v58.75–v58.77) corrigieron las fuentes del fondo opaco:
- v58.75: `overflow:visible` en `.sb` → revertido a `overflow:hidden`
- v58.76: `html,body{background:var(--nx-ui-canvas)}` en `parches-fase1-ui-motion.css` → quitado background de body
- v58.77: `.main, #app{background:...}` añadido por ChatGPT → eliminado

Sin embargo, el fondo blanco persistió en el iPhone del dueño.

**Causa raíz identificada:**
`body{background:transparent}` en `index.html` línea 299 no tenía `!important`.
`parches-fase1-ui-motion.css` se carga DESPUÉS en la cascada (vía loader dinámico).
Si iOS Safari sirve una versión cacheada del CSS viejo (que todavía tiene
`html,body{background:var(--nx-ui-canvas)}`), esa regla tiene la misma especificidad
pero llega DESPUÉS → gana y body queda opaco (#f0f4f8), tapando `#nxBgPhoto`.

El cambio de `?b=` en la query string no garantiza que Safari invalide su caché;
iOS Safari es conocido por ignorar cambios de query params en ciertos escenarios de
caché agresivo (BFCache, Service Workers, Add to Home Screen).

## Corrección

- `body{background:transparent}` → `body{background:transparent !important}` en `index.html`
  - Con `!important`, ningún CSS externo sin `!important` puede sobreescribirlo
  - El CSS viejo cacheado NO usa `!important` en esa regla → pierde
- APP_VERSION: `58.77` → `58.78`
- Cache-bust loader: `b=5946` → `b=5948`

## Archivos modificados

- `index.html` (línea 299: `!important`, línea 6460: APP_VERSION)
- `parches-seguros.js` (b=5948)
- `version.json` (nueva entrada)

## Riesgos

Ninguno. `!important` en body{background:transparent} solo refuerza la transparencia
que ya era el comportamiento deseado. El tema premium (`body.tema-premium`) usa
`background:#0B1220 !important` con mayor especificidad (`body.tema-premium` > `body`),
así que sigue ganando correctamente en modo oscuro.
