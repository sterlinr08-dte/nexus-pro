# Sidebar móvil — separación visual azul/blanco + animación por capas

## Solicitud del dueño

Después de publicar el sidebar móvil con carril azul e iconos fuera del panel blanco, el dueño pidió una terminación adicional:

- que la barra azul se sienta físicamente separada de la blanca;
- que la barra blanca y las letras se desplacen juntas;
- que los iconos permanezcan siempre encima del carril azul;
- que la barra azul tenga sombra;
- que al abrir/cerrar se perciba que el panel blanco sale desde debajo del azul.

No hubo autorización explícita de publicación en este turno. Se prepara primero en rama/preview.

## Implementación

Archivo:
`parches-sidebar-curva.css`

Solo dentro de `@media (max-width:768px)`:

1. **Contenedor transparente**
   - `nav#sbEl.sb` deja de ser la pieza blanca.
   - Ahora es únicamente el contenedor de las dos superficies.

2. **Carril azul elevado**
   - `::before` sigue siendo la silueta azul.
   - La línea decorativa blanca se integra dentro de su propio fondo.
   - Se aumenta `drop-shadow` hacia la derecha para separarlo claramente del panel blanco.
   - Queda visualmente por encima del panel.

3. **Panel blanco independiente**
   - `::after` pasa a ser el panel blanco.
   - Solapa 14px por debajo del carril azul.
   - Cerrado: se retrae completamente debajo del azul con
     `translateX(calc(-100% + 14px))`.
   - Abierto: `.mob-open::after { transform:translateX(0) }`.
   - Transición independiente de 300ms para que se perciba como una segunda pieza que sale desde detrás.

4. **Iconos**
   - No participan en la transición del panel.
   - Permanecen siempre sobre el carril azul.
   - Mantienen blanco limpio + activo translúcido.

5. **Letras / panel**
   - labels, subtítulos, badges, chevrons, nombre de marca y datos del usuario acompañan la salida del panel blanco.
   - Se usa fade + pequeño desplazamiento horizontal coordinado con el panel.

6. **Indicador activo**
   - Sigue empezando después de `--nx-rail`.
   - No invade la franja azul.

7. **Footer**
   - Sigue sobre la zona blanca.
   - Se sincroniza con el desplazamiento del panel.
