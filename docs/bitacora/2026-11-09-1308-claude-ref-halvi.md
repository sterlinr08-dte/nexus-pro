# Referencia de diseño: Halvi (Code and Chill)

- **Pedido.** El dueño mandó el enlace https://demo.codeandchill.store/halvi/ sin comentario.
- **Qué se hizo.** Se miró la página con Playwright a 1280 y 390 px y se agregó una fila al final de `docs/REFERENCIAS-DISENO.md`. Por la regla del 14-oct, se hizo igual en los 3 proyectos: nexus-pro, bayolcell-taller y studio-rd.
- **Qué es.** Una plantilla de pago de un tablero de salud. No se compró y no se copia código; solo se toman ideas.
- **Ideas anotadas:** datos en vivo como píldoras, gráfica de 7 días con hoy resaltado y la meta punteada, anillo de rayas, lista con hora y «Atrasada», cuadritos que se llenan, y tarjeta negra para lo más importante.
- **Estado.** Sin cambios de código. Ningún proyecto la usa todavía; falta que el dueño elija.
