# 2026-09-18 15:30 — Claude — Fix: panel blanco se veía translúcido (backdrop-filter heredado sin apagar)

## Para ChatGPT

El dueño reportó que el panel blanco se veía "transparente" y pidió que el azul se sienta "por
encima" del blanco (efecto de capa elevada). Encontré un bug real: al reescribir
`parches-sidebar-curva.css` para el diseño de carril+panel, se me olvidó apagar
`backdrop-filter: blur(24px) saturate(160%)` que trae `nav.sb` desde `NEXUS_SIDEBAR_V3`
(`parches-seguros-base.js`, sin `!important`, nunca sobrescrito en mi CSS nuevo). Como no
compite con nada, ese `backdrop-filter` seguía aplicado sobre mi `background:#fff!important` — el
panel se veía como vidrio esmerilado en vez de blanco sólido. Esto ya se había resuelto
correctamente en la versión anterior (todo-azul) pero se perdió al reescribir el archivo para este
diseño nuevo.

## Fix

- `nav.sb{backdrop-filter:none!important;-webkit-backdrop-filter:none!important}` agregado en los
  dos bloques donde se define el fondo blanco (desktop y móvil).
- Sombra del carril reforzada (`10px 0 24px rgba(15,23,64,.28), 2px 0 4px rgba(15,23,64,.14)`, antes
  más sutil) para que se lea como una pieza separada flotando sobre el panel blanco, no pegada al
  ras — respondiendo a "que el azul se vea como encima".

Build interno `b=5889 → b=5890`.
