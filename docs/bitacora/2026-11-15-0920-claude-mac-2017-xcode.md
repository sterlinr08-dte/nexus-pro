# La Mac del dueño (MacBook Pro 2017) no sirve para el plugin de Xcode

## Pregunta del dueño
«¿En una iPad se puede correr Xcode?» y luego: «Es una MacBook Pro 2017».

## Verificado en páginas oficiales de Apple (15-nov-2026)
- Xcode no existe para iPad. Ficha de Xcode en la App Store: «Requires macOS 26.6 or later and a Mac with Apple M1 chip or later». Para iPad existe Swift Playground, que es otra app.
- MacBook Pro 2017: aparece en la lista de macOS Ventura 13 (support.apple.com/102861) y no en la de macOS Sonoma 14 (105113). Su tope es Ventura 13.
- Tabla de requisitos de Xcode (developer.apple.com/xcode/system-requirements): el Xcode más nuevo que corre en Ventura es el 15.2 (pide Ventura 13.5). Xcode 26 pide macOS Sequoia 15.6; Xcode 27 pide macOS Tahoe 26.6.

## Sobre el plugin
Apple no publica una versión mínima de Xcode para el plugin. Una fuente secundaria (cellcog.ai, que cita documentación de Apple) dice que las herramientas para agentes externos llegan desde Xcode 26.3. No está confirmado en fuente oficial, pero cualquier versión con esas herramientas queda fuera del alcance de una Mac 2017.
