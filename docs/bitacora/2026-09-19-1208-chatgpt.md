# Ajuste en desarrollo — selector activo desktop ajustado al ancho del texto

## Solicitud del dueño

En una captura real del sidebar desktop, el dueño señaló que el selector activo se extendía demasiado hacia delante de las letras y pidió ajustarlo.

## Rama

`chatgpt/desktop-active-selector-fit`

Base:
`main@6557fb833b6ae3badc3b917fb8ffbb579f311bc9`

## Implementación

### CSS

En desktop expandido:
- el indicador activo deja de usar `right:18px`;
- pasa a `right:auto`;
- usa un ancho de respaldo compacto de `104px`;
- conserva el mismo radio, color, borde y sombra;
- el cambio de ancho tiene transición suave.

En desktop colapsado:
- se restaura el comportamiento de rail completo:
  - `left:10px`;
  - `right:10px`;
  - `width:auto`.

### JS

Se agregó `fitWidth(el)` al resorte del sidebar.

En desktop expandido:
- mide el ancho real del texto activo;
- incluye el badge cuando existe, como en **SOLICITUDES 4**;
- deja ~14px de respiración después del texto/badge;
- limita el ancho para no salir del panel blanco.

En móvil o sidebar colapsado:
- no aplica ancho dinámico;
- conserva el comportamiento anterior.

## Resultado esperado

El selector ya no se extiende de manera innecesaria hasta casi el borde derecho del panel. Debe terminar poco después de la palabra activa, manteniendo una proporción más elegante y profesional.

## Validación estática

- CSS balanceado: 105/105 llaves.
- Guard específico para móvil.
- Fallback específico para desktop colapsado.
- Ancho dinámico basado en el contenido activo.
