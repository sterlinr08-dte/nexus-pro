# Resumen de ciclo cerrado — WhatsApp para agentes

**Fecha:** 2026-09-21
**Autor:** Claude
**Solicitud:** El dueño pidió que al iniciar un nuevo ciclo (día 20), los agentes reciban un WhatsApp con el resumen del ciclo cerrado y del ciclo anterior.

## Diagnóstico

- El cierre automático del ciclo 2026-08 se ejecutó correctamente el 20-sep a las 00:05 RD.
- No existía plantilla ni función para enviar resumen de ciclo a los agentes.
- La plantilla `reporte_diario_agente` ya envía el acumulado diario, pero no un resumen de cierre.
- Los datos necesarios ya estaban en `seguros_cierres_ciclo` y `seguros_cierres_ciclo_agentes`.

## Implementación

### Plantilla WhatsApp
- **Nombre:** `resumen_ciclo_agente` (creada y aprobada por el dueño en Zernio/Meta)
- **Variables (12):** nombre, periodo cerrado, cobrado, entregado, transferido, recibido, saldo final, periodo anterior, cobrado anterior, saldo anterior, periodo nuevo, saldo inicial nuevo

### Edge Function
- **`whatsapp-resumen-ciclo-agentes`** (nueva)
- Lee el snapshot del ciclo cerrado desde `seguros_cierres_ciclo_agentes`
- Busca el ciclo anterior para comparación (si existe)
- Envía `resumen_ciclo_agente` a cada agente activo del cierre
- Soporta `dry: true` (simulación), `forzar: true` (reenviar), `periodo: "YYYY-MM"` (explícito)
- Guarda en `whatsapp_mensajes` y `auto_notificaciones_log`
- Protección de duplicados: no reenvía si ya se envió para ese periodo

### Migración SQL
- Constraint `whatsapp_mensajes_tipo_check`: agregado `resumen_ciclo_agente` y `reporte_diario_agente`
- `whatsapp_automatizaciones`: registrado `resumen_ciclo_agente` (orden 30)
- `whatsapp_enviar_resumen_ciclo(p_periodo)`: función interna que dispara la Edge Function vía `net.http_post`
- `seguros_cerrar_ciclo_automatico()`: actualizado para llamar `whatsapp_enviar_resumen_ciclo` tras un cierre exitoso

### Flujo automático
1. Cron `seguros-cierre-ciclo-20` dispara `seguros_cerrar_ciclo_automatico()` a las 00:05 RD del día 20
2. Si el cierre tiene éxito → llama `whatsapp_enviar_resumen_ciclo(periodo)`
3. Esta función POSTea a la Edge Function con el token de `cron_secretos.reporte_whatsapp`
4. La Edge Function envía el resumen a cada agente del snapshot
