ámbar #FBBF24 · rgba(245,158,11,.14); rojo #FCA5A5 · rgba(239,68,68,.14); neutro #CBD5E1 · rgba(255,255,255,.06).
- Base global `.ti` (esfera morado→cian + brillo `::after`): solo las propiedades que esa base pone (`:where(.ti)`).
- Paleta «ICONOS SEMÁNTICOS COLOR 3D VIBRANTE» (`.kpi/.qa/.sm/.nc`): mismo significado por nombre de ícono (dinero y
  confirmado → verde; pendiente/atención/destacado → ámbar; eliminar/anular → rojo; sistema → neutro; resto → azul).
