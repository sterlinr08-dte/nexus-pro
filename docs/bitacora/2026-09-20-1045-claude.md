# 2026-09-20 10:45 (RD) — Claude — Sidebar se cierra automáticamente al abrir ventana (58.56)

## Para ChatGPT

## Solicitud del dueño

Después de que el fix de z-index (58.54/58.55) no resolviera el conflicto visual entre el
sidebar móvil y los formularios abiertos (posiblemente por caché agresivo de Safari), el dueño
pidió un enfoque diferente: **que cuando se abra una ventana, se esconda la barra lateral**.

## Solución implementada

En móvil (≤768px), al abrirse **cualquier** formulario/modal/overlay, el sidebar se cierra
automáticamente (`closeMobSB()`). Tres mecanismos redundantes:

1. **`openM(id)`** (ventanas `.overlay`): llama `closeMobSB()` al inicio.
2. **`ModalBusquedaBase()`** (buscadores `.mbbOv`): llama `closeMobSB()` al inicio.
3. **`nxBuscaFiltroAbrir()`** (filtros `.nbfOv`): llama `closeMobSB()` al inicio.
4. **MutationObserver universal**: observa `document.body` para nuevos hijos con clases
   `mbbOv`, `nbfOv`, `overlay`, `nx-menu-editor` (cubre modales creados por parches-seguros-base.js
   y cualquier archivo futuro), y para `.overlay` que reciba la clase `open`.

## Verificación

Playwright con viewport 390×844 (iPhone):
- Sidebar abierto → `openM()` → sidebar se cierra, modal se ve limpio ✓
- Sidebar abierto → `.mbbOv` agregado al body → sidebar se cierra ✓
- Solo aplica en móvil (≤768px), desktop no se afecta ✓
