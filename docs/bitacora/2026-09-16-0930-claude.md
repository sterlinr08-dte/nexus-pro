## Revisión de diseño (Apple Design / interfaces fluidas)

- **El asa de arrastre (`.nxnov-handle`) no tiene ningún gesto atado.** Es un elemento puramente
  visual — no hay un solo `pointerdown`/`pointermove` en todo el archivo. Una pastilla horizontal
  arriba de una hoja es una señal universal de "arrástrame"; prometerlo visualmente y no
  responder al tacto es peor que no tener asa. Es el hallazgo de diseño más concreto.
- **El control segmentado (Pendientes/Resueltos) cambia de color al instante, sin ninguna pastilla
  que se deslice entre posiciones.** Los segmentados de iOS mueven físicamente el resaltado; aquí
  es un intercambio de clase CSS sin movimiento.
- Lo que sí está bien resuelto: `:active{transform:scale(...)}` en botones y tarjetas responde al
  toque, no al soltar; y las tres preferencias de accesibilidad (`prefers-reduced-motion`,
  `prefers-reduced-transparency`, `prefers-contrast`) están cubiertas desde el primer commit, cosa
  que a otras capas de este proyecto les costó una ronda de corrección aparte.
