# 2026-09-20 12:00 — WhatsApp Inbox compactación móvil (v58.57)

## Solicitud

El dueño pidió optimizar visualmente el Inbox de WhatsApp para móvil (iPhone 390–430px), reduciendo la altura de header, KPIs, acciones y filas de conversación para mostrar más chats en pantalla.

## Diagnóstico

Auditoría de la cascada CSS completa de `parches-whatsapp-*` (13 archivos inyectan `<style>` en `<head>`). El archivo dominante en móvil para dimensiones del Inbox es `parches-whatsapp-inbox-uhd.js`, que establece:

- Header `.nxCrmHomeHead`: min-height 72px, padding 10px 13px
- KPI `.nxWaProKpi`: min-height 62px, padding 7px 5px
- Fila `.nxWaRow`: min-height 62px, padding 9px
- Avatar `.nxWaAv`: 40px
- Toolbar `.nxWaListTools`: min-height 48px

Todos usan `!important`, así que la nueva capa debe cargar después para ganar la cascada.

## Implementación

### Nuevo archivo: `parches-whatsapp-inbox-compact-mobile.js`

Capa CSS pura (sin DOM, sin lógica, sin scroll, sin envío, sin pagos, sin Realtime). Solo aplica `@media(max-width:760px)`.

Reducciones principales:

| Elemento | Antes | Después |
|---|---|---|
| Header min-height | 72px | 42px |
| Hero icon | 40px | 28px |
| KPI card min-height | 62px | 38px |
| KPI value font | 15px | 13px |
| Container .nxWaPro padding | 12px | 6px |
| Contacts button height | 34px | 28px |
| Toolbar min-height | 48px | 36px |
| Row min-height | 62px | 48px |
| Avatar | 40px | 32px |
| Row margin-bottom | 5px | 3px |

Incluye breakpoint adicional `@media(max-width:360px)` para pantallas más pequeñas.
