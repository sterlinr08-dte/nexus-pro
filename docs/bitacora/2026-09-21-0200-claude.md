# Envío resumen ciclo 2026-08 a agentes — corrección de plantilla

**Fecha:** 2026-09-21
**Autor:** Claude

## Solicitud

El dueño autorizó enviar el resumen del ciclo cerrado 2026-08 a los agentes ESTERLIN y ROBINSON por WhatsApp.

## Problema encontrado

La Edge Function `whatsapp-resumen-ciclo-agentes` usaba el nombre de plantilla `resumen_ciclo_agente`, pero esa plantilla no existe en Meta/Zernio. El envío fallaba con:

```
"error": "Approved WhatsApp template resumen_ciclo_agente (es) was not found"
```

## Diagnóstico

Se consultó la API de Zernio (`/api/v1/whatsapp/templates`) para listar todas las plantillas aprobadas. Se encontraron 14 plantillas; la correcta para el resumen de ciclo es `reporte_novedades_ciclo_v1`.

## Correcciones aplicadas

1. **Edge Function** (`whatsapp-resumen-ciclo-agentes/index.ts`):
   - `TEMPLATE` cambiado de `"resumen_ciclo_agente"` a `"reporte_novedades_ciclo_v1"`
   - Check de plantilla aprobada cambiado de bloqueante (409) a warning + continuar
   - Redesplegada como v3

2. **Base de datos** (`whatsapp_automatizaciones`):
   - `plantilla_nombre` actualizado a `reporte_novedades_ciclo_v1` para el código `resumen_ciclo_agente`

3. **Edge Function diagnóstica** (`debug-templates`):
   - Desplegada temporalmente para consultar plantillas disponibles en Zernio
   - Puede eliminarse cuando no se necesite

## Resultado del envío

Envío exitoso del ciclo 2026-08 con `forzar: true`:

- **ESTERLIN**: ok (cobrado 140,800.00 / saldo final 1,398,310.00)
- **ROBINSON**: ok (cobrado 260,500.00 / entregado 68,000.00 / saldo final 329,190.00)

Ambos mensajes registrados en `whatsapp_mensajes` y `auto_notificaciones_log`.
