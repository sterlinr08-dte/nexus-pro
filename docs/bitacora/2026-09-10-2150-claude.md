## El arreglo: dejar de usar un icono

En vez de seguir peleando con reglas que no localizo, **el visto deja de ser un icono**.
`parches-whatsapp-visual-v7.js` construía:

```js
st.innerHTML = '<i class="ti '+inf.ico+'"></i>' + …
```

Ahora construye un carácter de texto:

```js
st.innerHTML = '<span class="nxWaMsgCheck">'+inf.txto+'</span>' + …
```

`estadoInfo()` gana un campo `txto` por estado: `○` enviando, `✓` enviado, `✓✓` entregado y leído, `!`
fallido. Se conserva el campo `ico` por si alguien lo necesita.

**El problema desaparece por construcción:** ninguna regla de iconos puede alcanzarlo, porque ya no hay
icono. No es un override más en la pila — es quitar el elemento del alcance del problema.

Estilo: 11 px con `letter-spacing:-3px` para que los dos checks se junten como el glifo de WhatsApp, y
azul `#53bdeb` cuando está leído.
