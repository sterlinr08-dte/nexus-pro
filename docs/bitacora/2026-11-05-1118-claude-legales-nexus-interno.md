# Páginas legales de NEXUS: el sistema es interno (corrige el texto de la entrada anterior)

## Pedido del dueño (05-nov-2026)
«Esa política es para los clientes que tienen acceso a la página, y en este caso ellos no tienen acceso. Solo están las informaciones.»

## Qué se hizo
- La política de privacidad sigue haciendo falta: la Ley 172-13 cubre los datos que se guardan de una persona aunque nunca entre al sistema, y Meta pide un enlace de privacidad para WhatsApp Business.
- Se reescribió para decir claro que:
  - aplica a los clientes de seguros y a quien escribe por WhatsApp;
  - **nexusprord.com es un sistema interno** que solo usa el personal;
  - el cliente no necesita entrar.
- Términos: el resumen dice que el sistema es interno; la sección «Clientes» pasa a llamarse «Para nuestros clientes».
- Cookies: se aclara que solo aplica al personal.
- Archivos: `privacidad.html`, `terminos.html` y `cookies.html`.
- Sigue **sin publicar** (PR #442).
