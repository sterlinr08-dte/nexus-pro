# 2026-09-20 10:20 (RD) — Claude — Refuerzo z-index en CSS dinámico (58.55)

## Para ChatGPT

## Problema

Tras publicar 58.54 (z-index del sidebar de 200 → 10700 en `index.html`), el dueño reportó
"Todavía sigue igual". El fix era correcto (confirmado con Playwright + DOM real), pero el
cambio vivía SOLO en el `<style>` inline de `index.html`, que Safari puede cachear agresivamente.

## Causa raíz

Si Safari sirve el `index.html` viejo desde caché, el sidebar sigue con `z-index:200`.
Los archivos cargados por `parches-seguros.js` (como `parches-sidebar-curva.css`) tienen un
parámetro `b=` de cache-bust que fuerza descarga fresca, pero el CSS no contenía el fix de
z-index — solo `index.html` lo tenía.

## Cambio

1. **`parches-sidebar-curva.css`** (sección `@media(max-width:768px)`):
   - `.sb, .sb.col`: agregado `z-index:10700 !important`
   - `#mobOverlay`: agregado `z-index:10699 !important`
   - Ahora, aunque `index.html` esté cacheado con el viejo z-index:200, el CSS dinámico lo
     sobrescribe con `!important`.

2. **`parches-seguros.js`**: cache-bust `b=5915 → b=5916`.

3. **`index.html`**: `APP_VERSION` 58.54 → 58.55.

4. **`version.json`**: entrada 58.55 documentando el refuerzo.

## Archivos modificados

- `parches-sidebar-curva.css`
- `parches-seguros.js`
- `index.html`
- `version.json`

## Verificación

Playwright con DOM real (nav.sb dentro de #app > .abody, .mbbOv como hijo directo de body):
- z-index:10700 → sidebar encima del modal ✓
- z-index:200 → modal encima del sidebar ✓
