# 2026-09-20 11:58 RD — ChatGPT + StitchDesign — Sidebar móvil por zonas, sin texto sobre el rail

## Solicitud del dueño

El dueño compartió una captura real del menú móvil y pidió usar **@StitchDesign** para:

- mejorar el acabado para que no se vea plano;
- corregir las letras que todavía se montan sobre la barra azul;
- garantizar que textos, títulos de sección y contenido del menú queden en la parte blanca.

## Diseño Stitch

Se creó `DESIGN.md` como fuente de verdad visual para NEXUS PRO.

Principio central del sidebar móvil:

- **Zona A — rail azul:** solo iconografía.
- **Zona B — panel blanco:** marca, labels, badges, chevrons, títulos de sección y footer.
- No se permiten márgenes negativos ni texto cruzando hacia el rail.
- La profundidad se expresa con sombra entre capas, no con glow/neón.

## Cambios implementados

### 1. Estructura real de filas móviles

Cada `.ni` reserva físicamente el rail:

`padding-left: calc(var(--nx-rail) + 12px)`

El primer icono de cada fila queda posicionado y centrado matemáticamente dentro del rail de 76px:

- `left:23px`
- icono de 30px
- centro resultante = 38px

Los labels ya no dependen de la suma accidental de ancho del icono + gap.

### 2. Labels totalmente en blanco

`.ni-l` deja de usar el margen que permitía regresar visualmente hacia el azul.

- label normal: `margin-left:0`
- label activo: `margin-left:0`
- selector activo empieza dentro del panel blanco

### 3. Títulos de sección

`.ss` (“PRINCIPAL”, “SISTEMA”) ahora empieza en:

`calc(var(--nx-rail) + 12px)`

Ya no cruza la frontera del rail.

### 4. Encabezado NEXUS PRO

El icono de marca queda centrado en el rail.
Nombre y versión empiezan 12px después del límite del rail, completamente en el panel blanco.

### 5. Footer

La tarjeta de usuario también se movió completamente a la zona blanca:

`margin-left: calc(var(--nx-rail) + 12px)`

Se agregó borde/sombra muy leve para que se sienta integrada y no plana.

### 6. Profundidad del panel blanco

El panel blanco pasa de un color plano a una gradación neutra muy sutil, con:

- borde whisper;
- sombra lateral;
- sombra inferior;
- highlight interior de 1px.

No se introducen nuevos colores de acento.
