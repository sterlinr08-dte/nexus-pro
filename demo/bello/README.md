# Demo Bello Accesorios (temporal)

Demo de ventas para un posible cliente del dueño, una tienda de accesorios de celulares. **No es parte de NEXUS PRO.**

- `index.html`: sistema (entrar, inicio, vender con modelo y color, inventario, clientes, historial, reportes).
- `mayoristas.html`: catálogo mayorista con precio por docena y por caja; el pedido sale por WhatsApp.
- `datos.js`: artículos y clientes de ejemplo. No hay base de datos; nada se guarda fuera del navegador.

Esta rama no se fusiona a `main`. Se borra cuando el dueño lo pida.
